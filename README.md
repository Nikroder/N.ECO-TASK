**N.ECO TASK** — это современная персональная «Операционная система продуктивности» (Life OS) для Android с открытым исходным кодом. Приложение объединяет список дел, тайм-блокинг календарь, трекер привычек, таймер глубокого фокуса (Pomodoro), **интерактивные виджеты на рабочем столе** и **систему автоматического обновления из GitHub Releases**.

---

## 📥 Как скачать и установить APK

1. Перейдите во вкладку [Releases на GitHub](https://github.com/Nikroder/N.ECO-TASK/releases).
2. Скачайте файл **`N.ECO-TASK.apk`**.
3. Установите на телефон.
4. **Автообновление:** При выходе новой версии на GitHub приложение само уведомит вас и предложит скачать и установить обновление в один клик!

---

## 🌟 Ключевые возможности

### 1. 🔄 Автообновления прямо из GitHub (In-App Auto-Updates)
* Приложение при запуске опрашивает GitHub Releases API (`Nikroder/N.ECO-TASK`).
* Если на GitHub опубликован более новый релиз с APK, отображается стильный диалог с описанием изменений.
* Встроенный загрузчик скачивает APK с визуальным индикатором прогресса и через системный `FileProvider` запускает установку.
* Кнопка ручной проверки обновлений доступна на экране «Аналитика».

### 2. ⚡ Умное управление задачами (Task Engine)
* **Парсинг естественного языка (NLP):**
  * Введите: `Завтра в 15:30 созвон с командой #работа !срочно`
  * N.ECO TASK на лету распознает дату, точное время, приоритет (`!срочно`, `!высокий`, `!средний`) и теги (`#работа`, `#спорт`, `#дом`).
* **Иерархия и организация:**
  * Категории: Личное, Работа, Учёба, Здоровье, Финансы.
  * 5 уровней приоритета с цветовой кодировкой.
  * Режимы отображения: Список и **Kanban-доска**.
  * Фильтрация: *Все, Сегодня, Предстоящие, Важные, Выполненные*.

### 3. 📅 Календарь и Тайм-блокинг (Time Blocking)
* Горизонтальная интерактивная лента дней.
* Тайм-блокинг: бронирование слотов времени (например, 10:00 - 11:30 «Глубокая работа»).
* Сетка задач и дедлайнов дня.

### 4. 🔥 Дисциплина и Трекер привычек (Habits & Streaks)
* Отслеживание ежедневных и гибких привычек.
* **Стрики (цепочки дней):** счетчик текущей серии и личного рекорда.
* **Карта дисциплины (Heatmap):** наглядная сетка активности а-ля GitHub за последние 16 недель.
* Быстрый чекин привычки в 1 клик с тактильной анимацией.

### 5. ⏱ Глубокий фокус (Pomodoro & Ambient Sounds)
* 3 режима: **Работа (25 мин)**, **Короткий перерыв (5 мин)**, **Длинный отдых (15 мин)**.
* Анимированный круговой таймер с обратным отсчетом.
* Встроенные атмосферные звуки: *Шум дождя, Уютный костёр, Белый шум*.
* Автоматическая статистика минут фокуса.

### 6. 📱 Интерактивные виджеты рабочего стола (Jetpack Glance)
* **Виджет «Задачи на сегодня» (4x3 / 4x4):**
  * Отображает актуальный список дел и прогресс выполнения.
  * **Интерактивные чекбоксы:** отмечайте выполненные задачи прямо с домашнего экрана телефона без необходимости открывать само приложение!
* **Виджет «Быстрые действия» (4x1):**
  * Компактная полоса для мгновенного перехода к созданию задачи, расписанию, Pomodoro и привычкам.

### 7. ⏰ Точные напоминания (AlarmManager & Notifications)
* Точные будильники (`SCHEDULE_EXACT_ALARM`), звенящие секунда в секунду даже в энергосберегающем режиме Android Doze.
* Интерактивные пуши с кнопками «✓ Выполнено» и «⏰ Отложить на 15 мин».
* Восстановление всех таймеров после перезагрузки смартфона (`BootReceiver`).

## 🛠 Технологический стек

* **Язык:** Kotlin 1.9.23
* **UI Toolkit:** Jetpack Compose (BOM 2024.04.01), Material 3 Expressive
* **Виджеты:** AndroidX Glance AppWidget 1.0.0
* **База данных:** Room 2.6.1 + KSP + Coroutines Flow (100% Offline-First)
* **Навигация:** Navigation Compose 2.7.7
* **Сборка:** Gradle 8.7 (Kotlin DSL, `build.gradle.kts`)
* **CI/CD:** GitHub Actions (автоматическая сборка APK и публикация релизов)

---

## 🚀 CI/CD и Сборка APK на GitHub

Каждый коммит или релиз автоматически собирается в облаке через **GitHub Actions**:
1. Workflow компилирует проект на виртуальной машине Ubuntu.
2. Собирает оптимизированный файл `N.ECO-TASK.apk`.
3. Загружает его в артефакты сборки и публикует в [GitHub Releases](https://github.com/Nikroder/N.ECO-TASK/releases).
4. Пользователи приложения сразу получают пуш-уведомление о доступном обновлении!
