**OmniPlan** — это современная персональная «Операционная система продуктивности» (Life OS) для Android. Приложение объединяет в едином бесшовном интерфейсе список дел, тайм-блокинг календарь, трекер привычек, таймер глубокого фокуса (Pomodoro) и **интерактивные виджеты на рабочем столе**.

---

## 🌟 Ключевые возможности

### 1. ⚡ Умное управление задачами (Task Engine)
* **Парсинг естественного языка (NLP):**
  * Введите: `Завтра в 15:30 созвон с командой #работа !срочно`
  * OmniPlan на лету распознает дату, точное время, приоритет (`!срочно`, `!высокий`, `!средний`) и теги (`#работа`, `#спорт`, `#дом`).
* **Иерархия и организация:**
  * Категории со своими цветами и иконками (Личное, Работа, Учёба, Здоровье, Финансы).
  * 5 уровней приоритета с цветовой индикацией.
  * Фильтрация: *Все, Сегодня, Предстоящие, Важные, Выполненные*.
  * Переключение между классическим списком и **Kanban-доской**.
  * Полнотекстовый локальный поиск.

### 2. 📅 Календарь и Тайм-блокинг (Time Blocking)
* **Горизонтальная лента дней:** быстрый выбор даты и наглядная индикация текущего дня.
* **Тайм-блокинг:** бронирование окон продуктивности (например, 10:00 - 11:30 «Глубокая работа»).
* **Сетка задач дня:** отображение всех дедлайнов и событий, запланированных на выбранную дату.

### 3. 🔥 Дисциплина и Трекер привычек (Habits & Streaks)
* Отслеживание ежедневных и периодических привычек (N дней в неделю).
* **Стрики (цепочки дней):** подсчет текущей серии и личного рекорда.
* **Карта дисциплины (Heatmap):** сетка активности а-ля GitHub за последние 16 недель.
* Быстрый чекин привычки одним тапом с плавной тактильной анимацией.

### 4. ⏱ Глубокий фокус (Pomodoro & Ambient Sounds)
* 3 режима: **Работа (25 мин)**, **Короткий перерыв (5 мин)**, **Длинный отдых (15 мин)**.
* Анимированный круговой таймер с обратным отсчетом.
* Встроенные атмосферные звуки: *Шум дождя, Уютный костёр, Белый шум*.
* Автоматическая запись сессий в статистику продуктивности.

### 5. 📱 Интерактивные виджеты рабочего стола (Jetpack Glance)
* **Виджет «Задачи на сегодня» (4x3 / 4x4):**
  * Отображает актуальный список дел и прогресс выполнения.
  * **Интерактивные чекбоксы:** отмечайте выполненные задачи прямо с домашнего экрана телефона без необходимости открывать само приложение!
  * Кнопка быстрого добавления новой задачи `+`.
* **Виджет «Быстрые действия» (4x1):**
  * Компактная полоса для мгновенного перехода к созданию задачи, расписанию, Pomodoro и привычкам.

### 6. ⏰ Точные напоминания и фоновые процессы
* **Гарантированное срабатывание (`AlarmManager` exact alarms):** напоминания звенят секунда в секунду даже в энергосберегающем режиме Android Doze.
* **Интерактивные пуш-уведомления (High Priority):**
  * Кнопка *«✓ Выполнено»* — помечает задачу выполненной прямо из шторки и обновляет виджеты.
  * Кнопка *«⏰ Отложить на 15 мин»* — переносит напоминание без входа в приложение.
* **Авто-восстановление при перезагрузке (`BootReceiver`):** все активные будильники автоматически восстанавливаются после перезагрузки смартфона.

## 🏗 Архитектура проекта

Приложение построено в соответствии с принципами **Clean Architecture** и **MVI / MVVM (Unidirectional Data Flow)**:

```
app/src/main/java/com/omniplan/app/
 ├── OmniPlanApp.kt                # Application-класс, инициализация каналов и репозиториев
 ├── core/
 │    ├── model/                   # Доменные модели: Task, Habit, TimeBlock, Category, Priority
 │    ├── util/                    # NlpTaskParser, DateTimeUtils
 │    └── notification/            # AlarmScheduler, AlarmReceiver, NotificationHelper, BootReceiver
 ├── data/
 │    ├── local/                   # Room Database, TypeConverters, Entities, DAOs
 │    └── repository/              # Реализация репозиториев (TaskRepositoryImpl, HabitRepositoryImpl)
 ├── domain/
 │    └── repository/              # Интерфейсы репозиториев
 ├── widget/                       # Jetpack Glance виджеты (TodayTasksWidget, QuickAddWidget, ActionCallback)
 └── ui/
      ├── MainActivity.kt          # Главный экран с NavigationBar и NavigationSuite
      ├── theme/                   # Material 3 Theme, Typography, True Dark / AMOLED Black
      ├── components/              # TaskCard, HabitCard, TimeBlockCard, AddTaskBottomSheet
      └── screens/
           ├── tasks/              # Экран задач (список, фильтры, поиск, kanban)
           ├── calendar/           # Экран календаря и тайм-блокинга
           ├── habits/             # Экран привычек и heatmap
           ├── focus/              # Экран фокуса (Pomodoro)
           └── analytics/          # Экран продуктивности и графиков
```

## 🛠 Технологический стек

* **Язык:** Kotlin 1.9.23 (Java 17/21 compatibility)
* **UI Toolkit:** Jetpack Compose (BOM 2024.04.01), Material 3 Expressive
* **Виджеты:** AndroidX Glance AppWidget 1.0.0
* **База данных:** Room 2.6.1 + KSP + Coroutines Flow (100% Offline-First)
* **Навигация:** Navigation Compose 2.7.7
* **Фоновые службы:** AlarmManager, BroadcastReceivers, WorkManager
* **Сборка:** Gradle 8.7 (Kotlin DSL, `build.gradle.kts`)

## 🚀 Как открыть и запустить проект

### Вариант 1: В Android Studio (Рекомендуется)
1. Откройте **Android Studio** (версии *Hedgehog*, *Iguana*, *Jellyfish*, *Koala* или новее).
2. Выберите **File -> Open...** и укажите папку проекта: `j:\Планировщик задач`.
3. Android Studio автоматически синхронизирует проект через Gradle, скачает SDK и подтянет зависимости.
4. Выберите эмулятор (Android 8.0 - Android 15) или реальное устройство.
5. Нажмите **Run ▶ (Shift + F10)**.

### Вариант 2: Сборка из командной строки
```powershell
# Проверка задач Gradle
.\gradlew.bat tasks

# Сборка Debug APK
.\gradlew.bat assembleDebug

# Запуск юнит-тестов
.\gradlew.bat test
```
Собранный файл APK будет находиться в папке:
`app/build/outputs/apk/debug/app-debug.apk`
